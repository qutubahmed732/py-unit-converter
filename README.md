# Python Unit Converter

A simple command-line application for converting between common units of length, weight, and temperature. Choose a category, enter a value and its source and target units, and the converter displays the result.

## Supported conversions

- **Length:** meters, kilometers, centimeters, millimeters, miles, feet, and inches
- **Weight:** grams, kilograms, milligrams, pounds, and ounces
- **Temperature:** Celsius, Fahrenheit, and Kelvin

## Run the application

Make sure Python is installed, then run:

```bash
python main.py
```
